## ✨ این پروژه چیست؟

MLM VPN Gateway یک سرور تونل مبتنی بر **VLESS** است که به‌طور کامل با **Python** و **FastAPI** نوشته شده — بدون هیچ باینری جانبی و بدون وابستگی سنگین. کار اصلی‌اش این است که ترافیک کاربر را از مسیری امن و مقاوم عبور دهد و در عین حال یک پنل مدیریتی تمیز برای ساخت و کنترل کاربران در اختیار بگذارد.

این هسته طوری ساخته شده که **پشت یک لایهٔ TLS ابری** (مثل Railway) قرار بگیرد؛ یعنی گواهی، دامنه و ترمینیشن TLS را زیرساخت میزبان فراهم می‌کند و سرور فقط روی منطق تونل تمرکز دارد.

> 🎯 در تجربهٔ نهایی، کاربر هرگز با این کد یا خط فرمان درگیر نمی‌شود؛ اپلیکیشن ویندوزی MLM VPN همه‌چیز را خودکار مستقر و مدیریت می‌کند.

## 🚀 امکانات

| | قابلیت |
|:--:|:--|
| 🔌 | تونل VLESS روی چند ترابرد: **WebSocket** و **XHTTP** (چند حالت) |
| 👥 | مدیریت نامحدود کاربر، هرکدام با UUID مستقل |
| 📊 | محدودیت **حجم** مصرفی به تفکیک هر کاربر |
| 🚦 | محدودیت **سرعت** اختصاصی (Mbps) برای هر کانفیگ |
| 🌐 | سقف **تعداد آی‌پی هم‌زمان** برای هر کاربر |
| ⏳ | **انقضای زمانی** خودکار بر پایهٔ روز |
| 🎛️ | تنظیم دستی **Fingerprint (uTLS)**، **ALPN** و **پورت** برای هر کانفیگ |
| 🗂️ | **گروه‌بندی کانفیگ‌ها** و لینک اشتراک تمیز |
| 🖥️ | داشبورد مدیریتی با آمار زنده، اتصالات و لاگ فعالیت |
| 💾 | ذخیرهٔ پایدار وضعیت روی دیسک (سازگار با Volume) |

## 🧩 معماری کوتاه

```
کلاینت  ──TLS──►  لبهٔ ابری (Railway)  ──►  MLM VPN Gateway  ──►  اینترنت
                  (دامنه + گواهی)           (FastAPI / VLESS)
```

- **زبان:** Python 3.12
- **وب‌فریم‌ورک:** FastAPI + Uvicorn
- **ترابرد:** VLESS over WebSocket / XHTTP
- **حالت اجرا:** کانتینر Docker (تصویر عمومی، آمادهٔ استقرار)

## ⚙️ متغیرهای محیطی

| متغیر | توضیح | پیش‌فرض |
|---|---|---|
| `ADMIN_PASSWORD` | رمز ورود به داشبورد مدیریتی | `—` |
| `SECRET_KEY` | کلید امضای نشست‌ها و رمز؛ برای پایداری ثابت نگه داشته می‌شود | خودکار |
| `DATA_DIR` | مسیر ذخیرهٔ وضعیت (بهتر است روی یک Volume باشد) | `/data` |
| `PORT` | پورت داخلی سرویس (توسط میزبان تنظیم می‌شود) | `8000` |

> 🔐 برای حفظ اطلاعات کاربران پس از هر ری‌استارت، یک **Volume دائمی** روی مسیر `DATA_DIR` وصل کنید.

## 🐳 استقرار

این مخزن یک `Dockerfile` آماده دارد و با هر تغییر، تصویر آن به‌صورت خودکار روی رجیستری منتشر می‌شود (GitHub Actions). استقرار به‌صورت خودکار توسط اپلیکیشن ویندوزی MLM VPN روی حساب ابری کاربر انجام می‌گیرد؛ نیازی به اجرای دستی نیست.

برای اجرای محلی (توسعه):

```bash
docker build -t mlmvpn-gateway .
docker run -p 8000:8000 -e ADMIN_PASSWORD=changeme -e DATA_DIR=/data mlmvpn-gateway
```

سپس داشبورد در آدرس `http://localhost:8000/dashboard` در دسترس است.
